# Beyond Retracing project website

**Beyond Retracing: Learning to Navigate from Exploration Memory**  
Zhiyang Han · Tianjin University

[Project page](https://artisgeneral.github.io/beyond-retracing/) · [Code and installation](https://github.com/ArtIsGeneral/BeyondRetracing) · [Model weights](https://github.com/ArtIsGeneral/BeyondRetracing/releases/tag/demo-28k-v1)

This repository hosts the GitHub Pages site, the 76 shortcut videos and the [interactive two-goal replay](https://artisgeneral.github.io/beyond-retracing/two-goals/). To run the navigation policy locally, follow the [inference instructions](https://github.com/ArtIsGeneral/BeyondRetracing#inference).

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000/`.

Scene observations come from HM3D and are subject to the [Matterport academic-use terms](https://matterport.com/legal/matterport-end-user-license-agreement-academic-use-model-data).
